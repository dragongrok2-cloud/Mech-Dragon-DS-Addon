# Mech Dragon — Dragon Survival Addon (Datapack)

Первый прототип аддона **Mech Dragon** для Dragon Survival 1.21.1.

## Описание
Холодный, расчётливый робот-дракон.  
Ест металл и редстоун.  
Высокий урон и броня, лазерные/энергетические атаки, ночное зрение, режим Перегрузки.  
Слабости: вода (короткое замыкание), перегрев в жаре/лаве, быстрый расход энергии, медленное восстановление.

## Установка
1. Установите **Dragon Survival** 1.21.1 + Geckolib
2. Положите этот датапак в папку `datapacks` мира **или** используйте Open Loader
3. Создайте новый мир (рекомендуется)
4. В алтаре дракона должен появиться **Mech Dragon**
